# lapencadev — portfolio personal ✨

Welcome to my portfolio!

> Dark mode, cursores neon, iconos flotantes y mucho amor tech ☕

---

## Qué hay dentro

El portfolio está organizado en secciones:

| Sección | Qué muestra |
|---|---|
| **Hero** | Presentación con terminal animada y stack chips |
| **About** | Timeline de experiencia |
| **Skills** | Cards con tecnologías |
| **Projects** | Algunos de mis proyectos visibles |
| **Talk** | Charla |
| **Community** | Cositas que hago en comunidad |
| **Contact** | Datos de contacto |

### Detalles de diseño

- **Colores:** fondo `#0a0a0f` + neons pink `#ff2d78`, cyan `#00ffe5`, yellow `#f5ff00`, purple `#b44fff`, orange `#ff6b2b`
- **Tipografías:** Unbounded (títulos), Space Mono (terminal/mono), DM Sans (cuerpo)
- **Extras:** cursor personalizado neon, 12 iconos decorativos flotantes en el fondo, animaciones de scroll con IntersectionObserver

## Cómo ejecutarlo en local

### Requisitos

- Node.js 18+
- npm (o pnpm/yarn, lo que uses)

### Pasos

```bash
# Clona el repo
git clone https://github.com/lapencadev/lapencadev-portfolio.git
cd lapencadev-portfolio

# Instala dependencias
npm install

# Arranca el servidor de desarrollo
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) en el navegador y listo.

### Otros comandos útiles

```bash
# Build de producción
npm run build

# Preview del build en local
npm run preview

# Lint
npm run lint
```

---

## Deploy

El proyecto tiene un `netlify.toml` configurado. Basta con conectar el repo en Netlify y elegir:

- **Build command:** `npm run build`
- **Publish directory:** `dist`

El deploy se lanza automáticamente en cada push a `main`.
