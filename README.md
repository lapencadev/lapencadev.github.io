## En local

```bash
git clone https://github.com/lapencadev/lapencadev-portfolio.git
cd lapencadev-portfolio
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173).

```bash
npm run build    # build de producción
npm run preview  # preview del build
npm run lint     # lint
```
